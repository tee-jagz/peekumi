# Getting help

- **A question about how to use or set up Peekumi:** ask in [Discussions](https://github.com/tee-jagz/peekumi/discussions). First read the [user guide](docs/USER-GUIDE.md) and the [setup guide](docs/SETUP.md). Many answers are there.
- **A defect:** open an issue with the **Bug report** form. Include the output of `peekumi doctor`.
- **An idea, a new language or a new agent provider:** open an issue with the matching form. See [CONTRIBUTING.md](CONTRIBUTING.md).
- **A security problem:** do not use an issue or a discussion. Follow [SECURITY.md](SECURITY.md).

Peekumi has one maintainer, so an answer can take some days.
