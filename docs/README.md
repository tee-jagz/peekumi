# Product and engineering documentation

This directory records Peekumi's product scope, architecture, validation results and original design context. It explains the mobile repository inspection experience and the engineering decisions behind it.

- `USER-GUIDE.md`: how to use every part of the interface, with labelled screenshots and an icon reference. Images live in `guide/` and are regenerated by `scripts/guide-screenshots.mjs`.
- `SETUP.md`: installation, phone pairing, devices and pull requests.
- `DEVELOPMENT.md`: building, running a checkout, tests, benchmarks and analysis limits.
- `MVP.md`: scope and interaction contract.
- `ARCHITECTURE.md`: runtime components, API and read-only boundaries.
- `RELATIONSHIPS.md`: supported static relationships, dependency rule configuration and analysis limits.
- `WORKFLOW.md`: comments, runs, reporting, verification and operational boundaries.
- `VALIDATION.md`: recorded test and benchmark evidence.
- `brand/`: the Peek mascot and Peekumi app icon artwork, with colours and usage.
- `context/`: the original specification and visual prototype archive.
